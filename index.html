The 5-Level Agentic Commerce Maturity Model

Traditional SEO optimizes for human clicks on blue links. Agentic Engine Optimization (AEO) ensures autonomous agents can verify stock, compare total landed costs, and execute transactions without visual ambiguity or bot-wall failures.

LEVEL 0 (0–24)

Invisible / Blocked

Aggressive WAF/CAPTCHAs block headless browsers, or empty client-side JS shells yield zero text without heavy execution.

LEVEL 1 (25–49)

Discoverable

SSR HTML and OpenGraph tags allow search agents to summarize pages, but missing JSON-LD forces brittle LLM price guessing.

LEVEL 2 (50–69)

Machine-Parseable

Rich Schema.org Product, Offer, GTIN, and stock states let answer engines cite accurate product cards.

LEVEL 3 (70–89)

DOM-Transactable

Semantic buttons, explicit ARIA labels, predictable variant selectors, and guest checkout let browser agents complete orders.

LEVEL 4 (90–100)

Autonomous-Native

Exposes /llms.txt, Schema BuyAction endpoints, OpenAPI specs, or MCP servers for direct API-level agentic purchasing.

Agent Discovery Manifest
