Architecture Standard

The 5-Level Agentic Commerce Maturity Model

Each pillar is scored from its observed checks. Pillars with no observable evidence are shown as N/A rather than scored as zero or as a guess. Without an observed purchase path, the result cannot exceed Level 2.

LEVEL 0 (0-24)

Invisible / Blocked

Critical rendering, access, challenge, or semantic barriers prevent dependable agent use.

LEVEL 1 (25-49)

Discoverable

Content can be found, but product and transaction signals remain ambiguous.

LEVEL 2 (50-69)

Machine-Parseable

Structured product information is readable, while action or checkout friction may remain.

LEVEL 3 (70-89)

DOM-Transactable

Semantic controls and a predictable guest purchase path support browser-based agents.

LEVEL 4 (90-100)

Autonomous-Native

Strong structured data plus explicit machine interfaces enable high-confidence agent workflows.

5-Pillar Evaluation Framework

1. Bot Access (22%)

Readable initial HTML, robots directives, challenge gates.

2. Structured Data (28%)

Product, Offer, price, currency, availability, identifiers.

3. Semantic DOM (22%)

Native controls, accessible names, labeled fields, descriptive links.

4. Checkout (18%)

Guest path, absence of forced accounts, visible shipping and tax.

5. Machine Interfaces (10%)

BuyAction targets, llms.txt, API descriptions and feeds.
